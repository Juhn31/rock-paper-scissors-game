# Rock Paper Scissors (C++)

My first game, built on 30 Sep 2026. I'm a first-year Mechatronics

## How to run
g++ rock_paper_scissors.cpp -o rps
./rps

Pick 1 (rock), 2 (paper), or 3 (scissors) and beat the computer.
